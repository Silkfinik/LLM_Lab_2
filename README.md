# Локальные LLM: воспроизводимые эксперименты, версия 2

Новые команды и полный порядок работы находятся в **[RUN_EXPERIMENTS.md](RUN_EXPERIMENTS.md)**.
Код версии 2 подготовлен без запуска; первым шагом выполните офлайн-тесты и smoke из инструкции.

- `research.py`: preflight, генерация, продолжение, анализ, независимое судейство и слепая разметка.
- `experiments/`: набор из 30 заданий, нативный Ollama API, проверки, статистика и визуализация.
- `tests/test_research.py`: регрессии без обращения к моделям.
- `streamlit_app.py`: интерфейс по новым результатам, без заранее зафиксированных выводов.
- `runs/`: новые исходные ответы, метаданные, телеметрия, CSV и графики; исключено из Git.

`benchmark.py`, `core/`, `app_pages/`, старые JSON и `ОТЧЕТ_ЛР2.md` оставлены как
историческая версия. Для новых измерений используйте `research.py`, а не `benchmark.py`.
Старые измерения не импортируются в новые автоматически.

Каждая серия сохраняет код/датасет SHA256, digest весов, настройки, сведения о
стенде и необработанные потоковые события. При отсутствии точного счётчика токенов
запрос считается ошибочным. Новых экспериментальных результатов в репозитории пока нет.
